CA/Browser Forum 於 2026-10-04 發布 Server Certificate Baseline Requirements **v2.3.1**，納入 Ballot SC-104（Set presence of AIA extension to SHOULD for Subscriber Certificates）。

原文的修訂內容可參考 GitHub 上的 [cabforum/servercert 提交紀錄](https://github.com/cabforum/servercert/commit/3574ae809e5f909b58ee4c26b7bac4a3b9e78421)，官方原文請以 [CA/Browser Forum 網站](https://cabforum.org/working-groups/server/baseline-requirements/documents/)公布者為準。
