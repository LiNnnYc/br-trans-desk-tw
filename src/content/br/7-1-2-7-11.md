> **Subscriber Certificate Key Usage**

> The acceptable Key Usage values vary based on whether the Certificate's `subjectPublicKeyInfo` identifies an RSA public key or an ECC public key. CAs MUST ensure the Key Usage is appropriate for the Certificate Public Key.

可接受之金鑰使用方式值視憑證之 `subjectPublicKeyInfo` 識別的是 RSA 公開金鑰或 ECC 公開金鑰而定。CA **應（MUST）**確保金鑰使用方式適合憑證公開金鑰。

> | **Key Usage**      | **Permitted** | **Required**     |
> | -----              | --            | ---              |
> | `digitalSignature` | Y             | SHOULD           |
> | `nonRepudiation`   | N             | --               |
> | `keyEncipherment`  | Y             | MAY              |
> | `dataEncipherment` | Y             | NOT RECOMMENDED  |
> | `keyAgreement`     | N             | --               |
> | `keyCertSign`      | N             | --               |
> | `cRLSign`          | N             | --               |
> | `encipherOnly`     | N             | --               |
> | `decipherOnly`     | N             | --               |

| **金鑰使用方式** | **允許** | **必要性** |
| ----- | -- | --- |
| `digitalSignature` | Y | 宜（SHOULD） |
| `nonRepudiation` | N | -- |
| `keyEncipherment` | Y | 得（MAY） |
| `dataEncipherment` | Y | 不建議（NOT RECOMMENDED） |
| `keyAgreement` | N | -- |
| `keyCertSign` | N | -- |
| `cRLSign` | N | -- |
| `encipherOnly` | N | -- |
| `decipherOnly` | N | -- |

**注意**：RSA 公開金鑰**應（MUST）**設定至少一項金鑰使用方式。`digitalSignature` 位元為使用現代協定（如 TLS 1.3）及安全加密套件所**必要（REQUIRED）**；`keyEncipherment` 位元**得（MAY）**主張以支援較舊協定（如 TLS 1.2）使用不安全加密套件時的情況。用戶**得（MAY）**希望確保金鑰隔離以降低此類舊有協定之風險，因此 CA **得（MAY）**簽發僅主張 `keyEncipherment` 位元之用戶憑證。對多數用戶而言，`digitalSignature` 位元已足夠，而希望以相同演算法混用不安全與安全加密套件之用戶，得選擇在同一憑證中同時主張 `digitalSignature` 與 `keyEncipherment`，但此方式**不建議（NOT RECOMMENDED）**。`dataEncipherment` 位元目前允許，但設定該位元**不建議（NOT RECOMMENDED）**，因其為待定禁止項目（<https://github.com/cabforum/servercert/issues/384>）。

> | **Key Usage**      | **Permitted** | **Required**     |
> | -----              | --            | ---              |
> | `digitalSignature` | Y             | MUST             |
> | `nonRepudiation`   | N             | --               |
> | `keyEncipherment`  | N             | --               |
> | `dataEncipherment` | N             | --               |
> | `keyAgreement`     | Y             | NOT RECOMMENDED  |
> | `keyCertSign`      | N             | --               |
> | `cRLSign`          | N             | --               |
> | `encipherOnly`     | N             | --               |
> | `decipherOnly`     | N             | --               |

| **金鑰使用方式** | **允許** | **必要性** |
| ----- | -- | --- |
| `digitalSignature` | Y | 應（MUST） |
| `nonRepudiation` | N | -- |
| `keyEncipherment` | N | -- |
| `dataEncipherment` | N | -- |
| `keyAgreement` | Y | 不建議（NOT RECOMMENDED） |
| `keyCertSign` | N | -- |
| `cRLSign` | N | -- |
| `encipherOnly` | N | -- |
| `decipherOnly` | N | -- |

**注意**：`keyAgreement` 位元目前允許，但設定該位元**不建議（NOT RECOMMENDED）**，因其為待定禁止項目（<https://github.com/cabforum/servercert/issues/384>）。
