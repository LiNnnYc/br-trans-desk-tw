> **CA Certificate Naming**

所有 `subject` 名稱**應（MUST）**依第 7.1.4 節所規定之方式編碼。

以下表格詳述可出現於 `AttributeTypeAndValue` 之 `type` 欄位中的可接受 `AttributeType`，以及 `value` 欄位允許之內容。

| **屬性名稱** | **出現要求** | **值** | **驗證** |
| --- | -- | ---- | - |
| `countryName` | 應（MUST） | CA 營業所所在國家之兩字母 ISO 3166-1 國家代碼。 | [第 3.2.2.3 節](#3223-verification-of-country) |
| `stateOrProvinceName` | 得（MAY） | 若存在，CA 之州或省資訊。 | [第 3.2.2.1 節](#3221-identity) |
| `localityName` | 得（MAY） | 若存在，CA 之地區資訊。 | [第 3.2.2.1 節](#3221-identity) |
| `postalCode` | 得（MAY） | 若存在，CA 之郵遞區號資訊。 | [第 3.2.2.1 節](#3221-identity) |
| `streetAddress` | 得（MAY） | 若存在，CA 之街道地址資訊。**得（MAY）**存在多個實例。 | [第 3.2.2.1 節](#3221-identity) |
| `organizationName` | 應（MUST） | CA 之名稱或商業名稱（DBA）。CA **得（MAY）**在此欄位中包含與已驗證名稱略有出入之資訊，例如常見變體或縮寫，前提是 CA 須記錄差異及所使用之縮寫為當地公認之縮寫；例如若官方記錄顯示「Company Name Incorporated」，CA **得（MAY）**使用「Company Name Inc.」或「Company Name」。 | [第 3.2.2.2 節](#3222-dbatradename) |
| `organizationalUnitName` | 此屬性**不得（MUST NOT）**包含於第 7.1.2.1 節所定義之根憑證機構憑證、第 7.1.2.5 節所定義之 TLS 下屬憑證機構憑證，或第 7.1.2.6 節所定義之技術受限 TLS 下屬憑證機構憑證中。此屬性**不宜（SHOULD NOT）**包含於其他類型之 CA 憑證中。 | - | - |
| `commonName` | 應（MUST） | 內容**宜（SHOULD）**為憑證之識別碼，使該憑證之名稱在簽發憑證機構所簽發之所有憑證中具有唯一性。 | |
| 任何其他屬性 | 不建議（NOT RECOMMENDED） | - | 參見[第 7.1.4.4 節](#7144-other-subject-attributes) |
