> **Technically Constrained TLS Subordinate CA Extensions**

> | **Extension**                     | **Presence**    | **Critical**          | **Description** |
> | ----                              | --              | --                    | --              |
> | `authorityKeyIdentifier`          | MUST            | N                     | See [Section 7.1.2.11.1](#712111-authority-key-identifier) |
> | `basicConstraints`                | MUST            | Y                     | See [Section 7.1.2.10.4](#712104-ca-certificate-basic-constraints) |
> | `certificatePolicies`             | MUST            | N                     | See [Section 7.1.2.10.5](#712105-ca-certificate-certificate-policies) |
> | `crlDistributionPoints`           | MUST            | N                     | See [Section 7.1.2.11.2](#712112-crl-distribution-points) |
> | `keyUsage`                        | MUST            | Y                     | See [Section 7.1.2.10.7](#712107-ca-certificate-key-usage) |
> | `subjectKeyIdentifier`            | MUST            | N                     | See [Section 7.1.2.11.4](#712114-subject-key-identifier) |
> | `extKeyUsage`                     | MUST[^eku_ca_en]   | N                     | See [Section 7.1.2.10.6](#712106-ca-certificate-extended-key-usage) |
> | `nameConstraints`                 | MUST            | \*[^name_constraints_en] | See [Section 7.1.2.5.2](#71252-technically-constrained-tls-subordinate-ca-name-constraints) |
> | `authorityInformationAccess`      | SHOULD          | N                     | See [Section 7.1.2.10.3](#712103-ca-certificate-authority-information-access) |
> | Signed Certificate Timestamp List | MAY             | N                     | See [Section 7.1.2.11.3](#712113-signed-certificate-timestamp-list) |
> | Any other extension               | NOT RECOMMENDED | -                     | See [Section 7.1.2.11.5](#712115-other-extensions) |

| **擴充欄位** | **必要性** | **關鍵性** | **說明** |
| ---- | -- | -- | -- |
| `authorityKeyIdentifier` | 應（MUST） | N | 參見[第 7.1.2.11.1 節](#712111-authority-key-identifier) |
| `basicConstraints` | 應（MUST） | Y | 參見[第 7.1.2.10.4 節](#712104-ca-certificate-basic-constraints) |
| `certificatePolicies` | 應（MUST） | N | 參見[第 7.1.2.10.5 節](#712105-ca-certificate-certificate-policies) |
| `crlDistributionPoints` | 應（MUST） | N | 參見[第 7.1.2.11.2 節](#712112-crl-distribution-points) |
| `keyUsage` | 應（MUST） | Y | 參見[第 7.1.2.10.7 節](#712107-ca-certificate-key-usage) |
| `subjectKeyIdentifier` | 應（MUST） | N | 參見[第 7.1.2.11.4 節](#712114-subject-key-identifier) |
| `extKeyUsage` | 應（MUST）[^eku_ca] | N | 參見[第 7.1.2.10.6 節](#712106-ca-certificate-extended-key-usage) |
| `nameConstraints` | 應（MUST） | \*[^name_constraints] | 參見[第 7.1.2.5.2 節](#71252-technically-constrained-tls-subordinate-ca-name-constraints) |
| `authorityInformationAccess` | 宜（SHOULD） | N | 參見[第 7.1.2.10.3 節](#712103-ca-certificate-authority-information-access) |
| Signed Certificate Timestamp（SCT）清單 | 得（MAY） | N | 參見[第 7.1.2.11.3 節](#712113-signed-certificate-timestamp-list) |
| 任何其他擴充欄位 | 不建議（NOT RECOMMENDED） | - | 參見[第 7.1.2.11.5 節](#712115-other-extensions) |

> [^eku_ca_en]: While [RFC 5280, Section 4.2.1.12](https://datatracker.ietf.org/doc/html/rfc5280#section-4.2.1.12) notes that this extension will generally only appear within end-entity certificates, these Requirements make use of this extension to further protect relying parties by limiting the scope of CA Certificates, as implemented by a number of Application Software Suppliers.

[^eku_ca]: 雖然 [RFC 5280 第 4.2.1.12 節](https://datatracker.ietf.org/doc/html/rfc5280#section-4.2.1.12) 指出，此擴充欄位通常僅出現於終端實體憑證，但本文件要求使用此擴充欄位，藉由限制 CA 憑證的適用範圍，進一步保護信賴憑證者（Relying Party）；此做法已由多家應用軟體供應商實作。

> [^name_constraints_en]: See [Section 7.1.2.10.8](#712108-ca-certificate-name-constraints) for further requirements, including regarding criticality of this extension.

[^name_constraints]: 有關此擴充欄位之進一步要求，包括是否標記為關鍵（critical）的相關要求，參見[第 7.1.2.10.8 節](#712108-ca-certificate-name-constraints)。
