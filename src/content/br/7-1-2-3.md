> **Technically Constrained Non-TLS Subordinate CA Certificate Profile**

> This Certificate Profile MAY be used when issuing a CA Certificate that will be considered Technically Constrained, and which will not be used to issue TLS certificates directly or transitively.

當簽發將被認定為技術受限、且不會直接或間接用於簽發 TLS 憑證之 CA 憑證時，**得（MAY）**使用本憑證剖繪。

| **欄位** | **說明** |
| ---- | ------ |
| `tbsCertificate` | |
|     `version` | **應（MUST）**為 v3(2) |
|     `serialNumber` | **應（MUST）**為大於 0 且小於 2¹⁵⁹ 之非序列號碼，並包含至少 64 位元的 CSPRNG 輸出值。 |
|     `signature` | 參見[第 7.1.3.2 節](#7132-signature-algorithmidentifier) |
|     `issuer` | **應（MUST）**與簽發憑證機構之 `subject` 欄位逐位元組完全相同。參見[第 7.1.4.1 節](#7141-name-encoding) |
|     `validity` | 參見[第 7.1.2.10.1 節](#712101-ca-certificate-validity) |
|     `subject` | 參見[第 7.1.2.10.2 節](#712102-ca-certificate-naming) |
|     `subjectPublicKeyInfo` | 參見[第 7.1.3.1 節](#7131-subjectpublickeyinfo) |
|     `issuerUniqueID` | **不得（MUST NOT）**存在 |
|     `subjectUniqueID` | **不得（MUST NOT）**存在 |
|     `extensions` | 參見[第 7.1.2.3.1 節](#71231-technically-constrained-non-tls-subordinate-ca-extensions) |
| `signatureAlgorithm` | 編碼值**應（MUST）**與 `tbsCertificate.signature` 逐位元組完全相同。 |
