> **Individual Validated**

> For a Subscriber Certificate to be Individual Validated, it MUST meet the following profile:

用戶憑證若欲符合個人驗證（Individual Validated），**應（MUST）**符合以下剖繪：

| **欄位** | **要求** |
| -- | ------- |
| `subject` | 參見下表。 |
| `certificatePolicies` | **應（MUST）**存在。**應（MUST）**以 `policyIdentifier` 主張保留憑證政策識別碼 `2.23.140.1.2.3`。參見[第 7.1.2.7.9 節](#71279-subscriber-certificate-certificate-policies)。 |
| 所有其他延伸欄位 | 參見[第 7.1.2.7.6 節](#71276-subscriber-certificate-extensions) |

所有 `subject` 名稱**應（MUST）**依第 7.1.4 節所規定之方式編碼。

表：個人驗證 `subject` 屬性

| **屬性名稱** | **出現要求** | **值** | **驗證** |
| --- | -- | --- | -- |
| `countryName` | 應（MUST） | 與主體相關之國家的兩字母 ISO 3166-1 國家代碼。若該國家無官方 ISO 3166-1 國家代碼，CA **應（MUST）**指定 ISO 3166-1 使用者自訂代碼 `XX`，表示尚未分配官方 ISO 3166-1 雙字母代碼。 | [第 3.2.3 節](#323-authentication-of-individual-identity) |
| `stateOrProvinceName` | 應（MUST）／得（MAY） | 若 `localityName` 不存在則**應（MUST）**存在，否則**得（MAY）**存在。若存在，**應（MUST）**包含主體之州或省資訊。 | [第 3.2.3 節](#323-authentication-of-individual-identity) |
| `localityName` | 應（MUST）／得（MAY） | 若 `stateOrProvinceName` 不存在則**應（MUST）**存在，否則**得（MAY）**存在。若存在，**應（MUST）**包含主體之地區資訊。 | [第 3.2.3 節](#323-authentication-of-individual-identity) |
| `postalCode` | 不建議（NOT RECOMMENDED） | 若存在，**應（MUST）**包含主體之郵遞區號資訊。 | [第 3.2.3 節](#323-authentication-of-individual-identity) |
| `streetAddress` | 不建議（NOT RECOMMENDED） | 若存在，**應（MUST）**包含主體之街道地址資訊。**得（MAY）**存在多個實例。 | [第 3.2.3 節](#323-authentication-of-individual-identity) |
| `organizationName` | 不建議（NOT RECOMMENDED） | 若存在，**應（MUST）**包含主體之名稱及／或商業名稱／商標名稱（DBA/tradename）。CA **得（MAY）**在此欄位中包含與已驗證名稱略有出入之資訊，例如常見變體或縮寫，前提是 CA 須記錄差異及所使用之縮寫為當地公認之縮寫。若兩者均包含，商業名稱／商標名稱**應（SHALL）**排列在前，其後以括號附上主體名稱。 | [第 3.2.3 節](#323-authentication-of-individual-identity) |
| `surname` | 應（MUST） | 主體之姓氏。 | [第 3.2.3 節](#323-authentication-of-individual-identity) |
| `givenName` | 應（MUST） | 主體之名字。 | [第 3.2.3 節](#323-authentication-of-individual-identity) |
| `organizationalUnitName` | 不得（MUST NOT） | - | - |
| `commonName` | 不建議（NOT RECOMMENDED） | 若存在，**應（MUST）**包含依[第 7.1.4.3 節](#7143-subscriber-certificate-common-name-attribute)從 `subjectAltName` 延伸欄位衍生之值。 | |
| 任何其他屬性 | 不建議（NOT RECOMMENDED） | - | 參見[第 7.1.4.4 節](#7144-other-subject-attributes) |

此外，`subject` 屬性**不得（MUST NOT）**僅包含 `.`、`-` 及 ` `（空格）等元資料字元，及／或任何其他表示值不存在、不完整或不適用之指示。
