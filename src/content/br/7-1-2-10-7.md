> **CA Certificate Key Usage**

> | **Key Usage**      | **Permitted** | **Required**     |
> | ----               | -             | -                |
> | `digitalSignature` | Y             | N[^ocsp_signing_en] |
> | `nonRepudiation`   | N             | --               |
> | `keyEncipherment`  | N             | --               |
> | `dataEncipherment` | N             | --               |
> | `keyAgreement`     | N             | --               |
> | `keyCertSign`      | Y             | Y                |
> | `cRLSign`          | Y             | Y                |
> | `encipherOnly`     | N             | --               |
> | `decipherOnly`     | N             | --               |

| **憑證金鑰用途（Key Usage）** | **可否設定** | **設定必要性** |
| ---- | - | - |
| `digitalSignature` | Y | N[^ocsp_signing] |
| `nonRepudiation` | N | -- |
| `keyEncipherment` | N | -- |
| `dataEncipherment` | N | -- |
| `keyAgreement` | N | -- |
| `keyCertSign` | Y | Y |
| `cRLSign` | Y | Y |
| `encipherOnly` | N | -- |
| `decipherOnly` | N | -- |

> [^ocsp_signing_en]: If a CA Certificate does not assert the `digitalSignature` bit, the CA Private Key MUST NOT be used to sign an OCSP Response. See [Section 7.3](#73-ocsp-profile) for more information.

[^ocsp_signing]: 若 CA 憑證未設定 `digitalSignature` 旗標位元，CA 私密金鑰**不得（MUST NOT）**用於簽章 OCSP 回應。更多資訊詳見[第 7.3 節](#73-ocsp-profile)。
