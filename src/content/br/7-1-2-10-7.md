> **CA Certificate Key Usage**

| **金鑰使用方式** | **允許** | **必要性** |
| ---- | - | - |
| `digitalSignature` | Y | N[^ocsp_signing] |
| `nonRepudiation` | N | -- |
| `keyEncipherment` | N | -- |
| `dataEncipherment` | N | -- |
| `keyAgreement` | N | -- |
| `keyCertSign` | Y | Y |
| `cRLSign` | Y | Y |
| `encipherOnly` | N | -- |
| `decipherOnly` | N | -- |

[^ocsp_signing]: 若 CA 憑證未主張 `digitalSignature` 位元，CA 私密金鑰**不得（MUST NOT）**用於簽署 OCSP 回應。詳見第 7.3 節。
