> **Subscriber Certificate Authority Information Access**

> The `AuthorityInfoAccessSyntax` MUST contain one or more `AccessDescription`s. Each `AccessDescription` MUST only contain a permitted `accessMethod`, as detailed below, and each `accessLocation` MUST be encoded as the specified `GeneralName` type.

`AuthorityInfoAccessSyntax` **應（MUST）**包含一個或多個 `AccessDescription`。每個 `AccessDescription` **應（MUST）**僅包含如下所詳述之允許 `accessMethod`，且每個 `accessLocation` **應（MUST）**依指定之 `GeneralName` 類型編碼。

> The `AuthorityInfoAccessSyntax` MAY contain multiple `AccessDescription`s with the same `accessMethod`, if permitted for that `accessMethod`. When multiple `AccessDescription`s are present with the same `accessMethod`, each `accessLocation` MUST be unique, and each `AccessDescription` MUST be ordered in priority for that `accessMethod`, with the most-preferred `accessLocation` being the first `AccessDescription`. No ordering requirements are given for `AccessDescription`s that contain different `accessMethod`s, provided that previous requirement is satisfied.

若該 `accessMethod` 允許，`AuthorityInfoAccessSyntax` **得（MAY）**包含具有相同 `accessMethod` 的多個 `AccessDescription`。當存在多個具有相同 `accessMethod` 的 `AccessDescription` 時，每個 `accessLocation` **應（MUST）**是唯一的，且每個 `AccessDescription` **應（MUST）**依該 `accessMethod` 之優先順序排列，最優先之 `accessLocation` 排在第一個 `AccessDescription`。對於包含不同 `accessMethod` 之 `AccessDescription`，在符合前述要求之前提下，不設置排序要求。

| **Access Method** | **Access Location** | **出現要求** | **最大數量** | **說明** |
| --- | ---- | - | - | --- |
| `id-ad-ocsp`（OID：1.3.6.1.5.5.7.48.1） | `uniformResourceIdentifier` | 得（MAY） | \* | 簽發憑證機構 OCSP 回應者之 HTTP URL。 |
| `id-ad-caIssuers`（OID：1.3.6.1.5.5.7.48.2） | `uniformResourceIdentifier` | 宜（SHOULD） | \* | 簽發憑證機構憑證之 HTTP URL。 |
| 任何其他值 | - | 不得（MUST NOT） | - | 不得使用其他 `accessMethod`。 |
