> **Subscriber Certificate Subject Alternative Name**

> For Subscriber Certificates, the Subject Alternative Name MUST be present and MUST contain at least one `dNSName` or `iPAddress` `GeneralName`. See below for further requirements about the permitted fields and their validation requirements.

用戶憑證之主體別名（Subject Alternative Name）**應（MUST）**存在，且**應（MUST）**包含至少一個 `dNSName` 或 `iPAddress` `GeneralName`。有關允許欄位及其驗證要求，詳見下文。

> If the `subject` field of the certificate is an empty SEQUENCE, this extension MUST be marked critical, as specified in [RFC 5280, Section 4.2.1.6](https://datatracker.ietf.org/doc/html/rfc5280#section-4.2.1.6). Otherwise, this extension MUST NOT be marked critical.

若憑證之 `subject` 欄位為空序列（empty SEQUENCE），本延伸欄位**應（MUST）**標記為關鍵，如 RFC 5280 第 4.2.1.6 節所規定。否則，本延伸欄位**不得（MUST NOT）**標記為關鍵。

表：`subjectAltName` 延伸欄位中之 `GeneralName`

| **名稱類型** | **允許** | **驗證** |
| --- | -- | ----- |
| `otherName` | N | - |
| `rfc822Name` | N | - |
| `dNSName` | Y | 該項目**應（MUST）**包含 CA 已依[第 3.2.2.4 節](#3224-validation-of-domain-authorization-or-control)驗證之完全吻合網域名稱（FQDN）或萬用網域名稱。萬用網域名稱**應（MUST）**依[第 3.2.2.6 節](#3226-wildcard-domain-validation)驗證其一致性。該項目**不得（MUST NOT）**包含內部名稱。自 2026-03-15 起，該項目**不得（MUST NOT）**包含以 IP 位址反向區域後綴結尾之網域名稱。該項目所含之完全吻合網域名稱，或萬用網域名稱之 FQDN 部分，**應（MUST）**完全由 P-Labels 或非保留 LDH Labels 以 U+002E 全停字元（「.」）連接而成。代表網際網路網域名稱系統根區域之零長度網域標籤**不得（MUST NOT）**包含其中（例如「example.com」**應（MUST）**編碼為「example.com」，**不得（MUST NOT）**編碼為「example.com.」）。 |
| `x400Address` | N | - |
| `directoryName` | N | - |
| `ediPartyName` | N | - |
| `uniformResourceIdentifier` | N | - |
| `iPAddress` | Y | 該項目**應（MUST）**包含 CA 已依[第 3.2.2.5 節](#3225-authentication-for-an-ip-address)確認申請者控制或已獲授予使用權之 IPv4 或 IPv6 位址。該項目**不得（MUST NOT）**包含保留 IP 位址。 |
| `registeredID` | N | - |

**注意**：作為 RFC 5280 之明確例外，P-Labels 允許不符合 IDNA 2003。本文件要求允許納入不符合 IDNA 2003 的 P-Labels，以支援更新版本之 Unicode 字元集及各種 IDNA 標準的其他改進。
