> **Organization Validated**

> For a Subscriber Certificate to be Organization Validated, it MUST meet the following profile:

用戶憑證若欲符合機構驗證（Organization Validated），**應（MUST）**符合以下剖繪：

| **欄位** | **要求** |
| --- | ------- |
| `subject` | 參見下表。 |
| `certificatePolicies` | **應（MUST）**存在。**應（MUST）**以 `policyIdentifier` 主張保留憑證政策識別碼 `2.23.140.1.2.2`。參見[第 7.1.2.7.9 節](#71279-subscriber-certificate-certificate-policies)。 |
| 所有其他延伸欄位 | 參見[第 7.1.2.7.6 節](#71276-subscriber-certificate-extensions) |

所有 `subject` 名稱**應（MUST）**依第 7.1.4 節所規定之方式編碼。

表：機構驗證 `subject` 屬性

| **屬性名稱** | **出現要求** | **值** | **驗證** |
| --- | -- | --- | -- |
| `domainComponent` | 得（MAY） | 若存在，此欄位**應（MUST）**包含網域名稱中的一個網域標籤（Domain Label）。網域名稱之 `domainComponent` 欄位**應（MUST）**按單一有序序列包含該網域名稱的所有網域標籤。網域標籤**應（MUST）**以與 DNS 協定在線上（on-wire）表示網域名稱相反之順序編碼，使最靠近根的網域標籤排在最前面。**得（MAY）**存在多個實例。 | [第 3.2 節](#32-initial-identity-validation) |
| `countryName` | 應（MUST） | 與主體相關之國家的兩字母 ISO 3166-1 國家代碼。若該國家無官方 ISO 3166-1 國家代碼，CA **應（MUST）**指定 ISO 3166-1 使用者自訂代碼 `XX`，表示尚未分配官方 ISO 3166-1 雙字母代碼。 | [第 3.2.2.1 節](#3221-identity) |
| `stateOrProvinceName` | 應（MUST）／得（MAY） | 若 `localityName` 不存在則**應（MUST）**存在，否則**得（MAY）**存在。若存在，**應（MUST）**包含主體之州或省資訊。 | [第 3.2.2.1 節](#3221-identity) |
| `localityName` | 應（MUST）／得（MAY） | 若 `stateOrProvinceName` 不存在則**應（MUST）**存在，否則**得（MAY）**存在。若存在，**應（MUST）**包含主體之地區資訊。 | [第 3.2.2.1 節](#3221-identity) |
| `postalCode` | 不建議（NOT RECOMMENDED） | 若存在，**應（MUST）**包含主體之郵遞區號資訊。 | [第 3.2.2.1 節](#3221-identity) |
| `streetAddress` | 不建議（NOT RECOMMENDED） | 若存在，**應（MUST）**包含主體之街道地址資訊。**得（MAY）**存在多個實例。 | [第 3.2.2.1 節](#3221-identity) |
| `organizationName` | 應（MUST） | 主體之名稱及／或商業名稱／商標名稱（DBA/tradename）。CA **得（MAY）**在此欄位中包含與已驗證名稱略有出入之資訊，例如常見變體或縮寫，前提是 CA 須記錄差異及所使用之縮寫為當地公認之縮寫；例如若官方記錄顯示「Company Name Incorporated」，CA **得（MAY）**使用「Company Name Inc.」或「Company Name」。若兩者均包含，商業名稱／商標名稱**應（SHALL）**排列在前，其後以括號附上主體名稱。 | [第 3.2.2.2 節](#3222-dbatradename) |
| `surname` | 不得（MUST NOT） | - | - |
| `givenName` | 不得（MUST NOT） | - | - |
| `organizationalUnitName` | 不得（MUST NOT） | - | - |
| `commonName` | 不建議（NOT RECOMMENDED） | 若存在，**應（MUST）**包含依[第 7.1.4.3 節](#7143-subscriber-certificate-common-name-attribute)從 `subjectAltName` 延伸欄位衍生之值。 | |
| 任何其他屬性 | 不建議（NOT RECOMMENDED） | - | 參見[第 7.1.4.4 節](#7144-other-subject-attributes) |

此外，`subject` 屬性**不得（MUST NOT）**僅包含 `.`、`-` 及 ` `（空格）等元資料字元，及／或任何其他表示值不存在、不完整或不適用之指示。
