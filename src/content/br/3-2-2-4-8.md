> **IP Address**

> Confirming the Applicant's control over the FQDN by confirming that the Applicant controls an IP address returned from a DNS lookup for A or AAAA records for the FQDN in accordance with Section 3.2.2.5.

依據第 3.2.2.5 節，透過確認申請者（Applicant）控制該 FQDN 經 DNS 查詢 A 或 AAAA 紀錄後回傳的 IP 位址（IP Address），以確認申請者對該 FQDN 的控制權。

> CAs performing validations using this method MUST implement Multi-Perspective Issuance Corroboration as specified in Section 3.2.2.9. To count as corroborating, a Network Perspective MUST observe the same IP address as the Primary Network Perspective.

使用此方法進行驗證的 CA **應（MUST）**實作第 3.2.2.9 節所規範之多視角簽發佐證（Multi-Perspective Issuance Corroboration）。為了計入佐證，網路視角（Network Perspective）**應（MUST）**觀察到與主要網路視角（Primary Network Perspective）相同的 IP 位址。

> **Note**: Once the FQDN has been validated using this method, the CA MUST NOT issue Certificates for other FQDNs that end with all the labels of the validated FQDN unless the CA performs separate validations for each of those other FQDNs using authorized methods. This method is NOT suitable for validating Wildcard Domain Names.

**注意**：一旦 FQDN 使用此方法驗證完成，CA **不得（MUST NOT）**針對以該驗證 FQDN 之所有標籤（labels）結尾的其他 FQDN 簽發憑證，除非 CA 使用經授權的方法對該等其他 FQDN 分別進行驗證。此方法不適用於驗證萬用網域名稱（Wildcard Domain Names）。

> Effective March 15, 2026:
> - The CA MUST NOT rely on this method.
> - Prior validations using this method and validation data gathered according to this method MUST NOT be used to issue Subscriber Certificates.

自 2026-03-15 起：
- CA **不得（MUST NOT）**依賴此方法。
- 先前使用此方法進行的驗證，以及依據此方法收集的驗證資料，**不得（MUST NOT）**用於簽發用戶憑證。
