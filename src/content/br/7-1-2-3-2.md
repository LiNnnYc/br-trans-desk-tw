> **Technically Constrained Non-TLS Subordinate CA Certificate Policies**

> If present, the Certificate Policies extension MUST be formatted as one of the two tables below:

若存在，憑證政策延伸欄位**應（MUST）**符合以下兩表之一的格式：

表：無政策限制（關係企業 CA）

| **欄位** | **出現要求** | **內容** |
| --- | --- | ---- |
| `policyIdentifier` | 應（MUST） | 當簽發憑證機構希望表示無任何政策限制時，下屬憑證機構**應（MUST）**為簽發憑證機構之關係企業。憑證政策延伸欄位**應（MUST）**僅包含單一 `PolicyInformation` 值，且**應（MUST）**包含 `anyPolicy` 政策識別碼。 |
|     `anyPolicy` | 應（MUST） | |
| `policyQualifiers` | 不建議（NOT RECOMMENDED） | 若存在，**應（MUST）**僅包含下表所列之允許 `policyQualifiers`。 |

表：受政策限制

| **欄位** | **出現要求** | **內容** |
| --- | --- | ---- |
| `policyIdentifier` | 應（MUST） | 下列政策識別碼之一： |
|     [保留憑證政策識別碼](#7161-reserved-certificate-policy-identifiers) | 不得（MUST NOT） | |
|     `anyPolicy` | 不得（MUST NOT） | `anyPolicy` 政策識別碼**不得（MUST NOT）**存在。 |
|     任何其他識別碼 | 得（MAY） | 若存在，**應（MUST）**由 CA 記錄於其憑證政策及／或憑證業務作業基準中。 |
| `policyQualifiers` | 不建議（NOT RECOMMENDED） | 若存在，**應（MUST）**僅包含下表所列之允許 `policyQualifiers`。 |

表：允許之 `policyQualifiers`

| **Qualifier ID** | **出現要求** | **欄位類型** | **內容** |
| --- | -- | -- | --- |
| `id-qt-cps`（OID：1.3.6.1.5.5.7.2.1） | 得（MAY） | `IA5String` | 簽發憑證機構之憑證政策、憑證業務作業基準、信賴憑證者協議或其他由簽發憑證機構提供之線上政策資訊指引的 HTTP 或 HTTPS URL。 |
| 任何其他 qualifier | 不得（MUST NOT） | - | - |
