> **OCSP Responder Certificate Policies**

若存在，憑證政策延伸欄位**應（MUST）**包含至少一個 `PolicyInformation`。每個 `PolicyInformation` **應（MUST）**符合以下剖繪：

| **欄位** | **出現要求** | **內容** |
| --- | -- | ----- |
| `policyIdentifier` | 應（MUST） | 下列政策識別碼之一： |
|     保留憑證政策識別碼 | 不建議（NOT RECOMMENDED） | |
|     `anyPolicy` | 不建議（NOT RECOMMENDED） | |
|     任何其他識別碼 | 不建議（NOT RECOMMENDED） | 若存在，**應（MUST）**由 CA 定義並記錄於其憑證政策及／或憑證業務作業基準中。 |
| `policyQualifiers` | 不建議（NOT RECOMMENDED） | 若存在，**應（MUST）**僅包含下表所列之允許 `policyQualifiers`。 |

表：允許之 `policyQualifiers`

| **Qualifier ID** | **出現要求** | **欄位類型** | **內容** |
| --- | -- | -- | --- |
| `id-qt-cps`（OID：1.3.6.1.5.5.7.2.1） | 得（MAY） | `IA5String` | 簽發憑證機構之憑證政策、憑證業務作業基準、信賴憑證者協議或其他由簽發憑證機構提供之線上政策資訊指引的 HTTP 或 HTTPS URL。 |
| 任何其他 qualifier | 不得（MUST NOT） | - | - |

**注意**：由於憑證政策延伸欄位可用於限制憑證之適用用途，不正確的政策可能導致 OCSP 回應者憑證驗證失敗，進而產生無效的 OCSP 回應。納入 `anyPolicy` 政策可降低此風險，但會增加用戶端處理複雜度及互通性問題。
