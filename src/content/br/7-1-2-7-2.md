> **Domain Validated**

> For a Subscriber Certificate to be Domain Validated, it MUST meet the following profile:

用戶憑證若欲符合網域驗證（Domain Validated），**應（MUST）**符合以下剖繪：

| **欄位** | **要求** |
| --- | ------- |
| `subject` | 參見下表。 |
| `certificatePolicies` | **應（MUST）**存在。**應（MUST）**以 `policyIdentifier` 主張保留憑證政策識別碼 `2.23.140.1.2.1`。參見[第 7.1.2.7.9 節](#71279-subscriber-certificate-certificate-policies)。 |
| 所有其他延伸欄位 | 參見[第 7.1.2.7.6 節](#71276-subscriber-certificate-extensions) |

所有 `subject` 名稱**應（MUST）**依第 7.1.4 節所規定之方式編碼。

表：網域驗證 `subject` 屬性

| **屬性名稱** | **出現要求** | **值** | **驗證** |
| -- | --- | --- | -- |
| `countryName` | 得（MAY） | 與主體相關之國家的兩字母 ISO 3166-1 國家代碼。 | [第 3.2.2.3 節](#3223-verification-of-country) |
| `commonName` | 不建議（NOT RECOMMENDED） | 若存在，**應（MUST）**包含依[第 7.1.4.3 節](#7143-subscriber-certificate-common-name-attribute)從 `subjectAltName` 延伸欄位衍生之值。 | |
| 任何其他屬性 | 不得（MUST NOT） | - | - |
