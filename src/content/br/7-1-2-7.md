> **Subscriber (Server) Certificate Profile**

> | **Field**                  | **Description** |
> | ----                        | ------          |
> | `tbsCertificate`           | |
> |     `version`              | MUST be v3(2) |
> |     `serialNumber`         | MUST be a non-sequential number greater than zero (0) and less than 2¹⁵⁹ containing at least 64 bits of output from a CSPRNG. |
> |     `signature`            | See [Section 7.1.3.2](#7132-signature-algorithmidentifier) |
> |     `issuer`               | MUST be byte-for-byte identical to the `subject` field of the Issuing CA. See [Section 7.1.4.1](#7141-name-encoding) |
> |     `validity`             | |
> |          `notBefore`       | A value within 48 hours of the certificate signing operation. |
> |          `notAfter`        | See [Section 6.3.2](#632-certificate-operational-periods-and-key-pair-usage-periods) |
> |     `subject`              | See [Section 7.1.2.7.1](#71271-subscriber-certificate-types) |
> |     `subjectPublicKeyInfo` | See [Section 7.1.3.1](#7131-subjectpublickeyinfo) |
> |     `issuerUniqueID`       | MUST NOT be present |
> |     `subjectUniqueID`      | MUST NOT be present |
> |     `extensions`           | See [Section 7.1.2.7.6](#71276-subscriber-certificate-extensions) |
> | `signatureAlgorithm`       | Encoded value MUST be byte-for-byte identical to the `tbsCertificate.signature`. |
> | `signature`                | |

| **欄位** | **說明** |
| ---- | ------ |
| `tbsCertificate` | |
|     `version` | **應（MUST）**為 v3(2) |
|     `serialNumber` | **應（MUST）**為大於 0 且小於 2¹⁵⁹ 之非序列號碼，並包含至少 64 位元的 CSPRNG 輸出值。 |
|     `signature` | 參見[第 7.1.3.2 節](#7132-signature-algorithmidentifier) |
|     `issuer` | **應（MUST）**與簽發憑證機構之 `subject` 欄位逐位元組完全相同。參見[第 7.1.4.1 節](#7141-name-encoding) |
|     `validity` | |
|          `notBefore` | 憑證簽署作業 48 小時內之值。 |
|          `notAfter` | 參見[第 6.3.2 節](#632-certificate-operational-periods-and-key-pair-usage-periods) |
|     `subject` | 參見[第 7.1.2.7.1 節](#71271-subscriber-certificate-types) |
|     `subjectPublicKeyInfo` | 參見[第 7.1.3.1 節](#7131-subjectpublickeyinfo) |
|     `issuerUniqueID` | **不得（MUST NOT）**存在 |
|     `subjectUniqueID` | **不得（MUST NOT）**存在 |
|     `extensions` | 參見[第 7.1.2.7.6 節](#71276-subscriber-certificate-extensions) |
| `signatureAlgorithm` | 編碼值**應（MUST）**與 `tbsCertificate.signature` 逐位元組完全相同。 |
| `signature` | |
