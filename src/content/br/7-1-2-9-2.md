> **Precertificate Profile Extensions - Precertificate CA Issued**

這些延伸欄位適用於由第 7.1.2.4 節所定義之預憑證簽署 CA 憑證所簽發的預憑證。對於此類預憑證，若 `authorityKeyIdentifier` 存在於憑證中，則在預憑證中會被修改，如 RFC 6962 第 3.2 節所述。

| **延伸欄位** | **出現要求** | **關鍵** | **說明** |
| ---- | - | - | ---- |
| Precertificate Poison（OID：1.3.6.1.4.1.11129.2.4.3） | 應（MUST） | Y | 參見[第 7.1.2.9.3 節](#71293-precertificate-poison) |
| `authorityKeyIdentifier` | \* | \* | 參見[第 7.1.2.9.4 節](#71294-precertificate-authority-key-identifier) |
| Signed Certificate Timestamp List | 不得（MUST NOT） | - | |
| 任何其他延伸欄位 | \* | \* | 所有其他延伸欄位之順序、關鍵性及編碼值**應（MUST）**與憑證之 `extensions` 欄位逐位元組完全相同 |
